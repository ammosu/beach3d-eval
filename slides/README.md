# 投影片與試玩

```bash
python3 start.py      # 只需要 Python 3；會自動開 http://localhost:8730
```

- 8730：投影片（←→ 換頁），最後一頁「實際試玩」連到下列場景
- 8731：主版本（遊戲模式、三欄比較、遊覽、角色並排、單件檢視）
- 8732：codex 高推理版本的場景
- 8733：Opus 5.5 版本的場景

直接雙擊 index.html 也能看投影片與影片，但試玩頁需要先執行 `start.py`（瀏覽器不允許用 file:// 載入 3D 模組與模型）。

更新場景後重新打包：在專案根目錄執行 `tools/build_live.sh`。
