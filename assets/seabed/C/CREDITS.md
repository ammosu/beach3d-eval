# 潛水海底 C 組素材出處

用 MCP for Blender 從 Poly Pizza／Sketchfab 匯入（魚的骨架模型以靜止姿勢匯出成靜態網格），再用 `reef/tripo/prep.py` 合併、減面、縮貼圖；魚轉成頭朝 +X（`z90`）。遊戲載入時再依 A 組的規則正規化：魚長度＝1；其餘底部貼 y＝0、最長邊＝1。
